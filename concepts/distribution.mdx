## Support claim levels

| Claim | Meaning |
| --- | --- |
| `verified` | Current validation command or host smoke test exists. |
| `install-target` | Manifest present; live execution may be environment-dependent. |
| `context-only` | Host ingests context; slash-command support is not claimed. |
