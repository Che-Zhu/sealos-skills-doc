Sealos Skills 是面向 AI Agent 的 plugin-first 技能包。它会检查项目并准备部署产物，连接云数据库与对象存储，构建或复用容器镜像，然后部署到 [Sealos Cloud](https://sealos.io)。

## 你可以做什么

- 从本地目录或 GitHub 仓库部署
- 创建并连接云数据库（Postgres、MySQL、Redis、MongoDB）
- 创建并连接 S3 兼容对象存储
- 在本地只读画布中查看已部署资源
- 使用 SDK 集成构建 Sealos Desktop 应用
