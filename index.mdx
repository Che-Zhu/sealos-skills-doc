Sealos Skills is a plugin-first skill pack for AI agents. It inspects a project, prepares deployment artifacts, connects cloud databases and object storage, builds or reuses container images, and deploys to [Sealos Cloud](https://sealos.io).

<Note>
This documentation site is the **single source of truth** for skill behavior, pipeline contracts, and user-facing specifications. The [`sealos-skills`](https://github.com/labring/sealos-skills) repository implements these docs.
</Note>

## What you can do

- Deploy a local or GitHub project to Sealos Cloud
- Create and wire cloud databases (Postgres, MySQL, Redis, MongoDB)
- Create and wire S3-compatible object storage
- View deployed resources in a local read-only canvas
- Build Sealos Desktop apps with SDK integration
