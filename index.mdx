Sealos Skills is a plugin-first skill pack for AI agents. It inspects a project and prepares deployment artifacts. It connects cloud databases and object storage. It builds or reuses container images. Then it deploys to [Sealos Cloud](https://sealos.io).

## What you can do

- Deploy from a local folder or a GitHub repository
- Create and connect cloud databases (Postgres, MySQL, Redis, MongoDB)
- Create and connect S3-compatible object storage
- View deployed resources in a local read-only canvas
- Build Sealos Desktop apps with SDK integration
