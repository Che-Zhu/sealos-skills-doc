## 目的

Phase U2 应用更新，不重新运行评估、发现或模板生成。

## 输入

| 输入 | 来源 |
| --- | --- |
| 更新计划 | Phase U1 |
| 记录的工作负载映射 | `state.json` |

## 输出

| 输出 | 说明 |
| --- | --- |
| 已更新工作负载 | 新 digest 或已重启 rollout |
| Pull secret 更新 | 私有 GHCR 镜像需要时 |

## 流程

**镜像更新：** 更新每个记录的工作负载类型、名称与容器。不得仅凭应用名猜测目标。

**GHCR namespace 规则：** 应用中所有私有 GHCR 镜像须共享一个规范化 namespace。检查全服务集，不仅选定服务。冲突时在云端变更前停止。

**仅重启：** 滚动每个选定的 Deployment、StatefulSet 或 DaemonSet，不改变镜像。CronJob 无活跃 rollout；仅验证镜像与调度。

复用已有应用与网络入口。一个应用 pull secret；仅需要认证的工作负载引用它。

## 停止条件

| 结果 | 条件 |
| --- | --- |
| **STOP** | namespace 冲突或验证前应用失败 |
| **CONTINUE → Phase U3** | 所有选定变更已应用 |

## 验收标准

- 目标与记录的工作负载映射匹配
- 需要认证的工作负载 pull secret 一致
