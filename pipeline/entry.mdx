## Project sources

Sealos Deploy accepts three project sources:

| Source | Behavior |
| --- | --- |
| GitHub repository URL | Clone the repository, then deploy |
| Local project directory | Deploy the specified directory |
| Current project | Deploy the current working directory when no URL or path is given |

See [Phase 0](/pipeline/phases/phase-0-preflight) for source materialization rules.

## Deploy log

Every run creates a unified deploy log. The log spans all phases. It records phase boundaries, key decisions, failure reasons, and retries.

The agent must not omit phase boundaries from the log.
