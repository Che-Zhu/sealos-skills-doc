## 项目来源

Sealos Deploy 接受三种项目来源：

| 来源 | 行为 |
| --- | --- |
| GitHub 仓库 URL | 克隆仓库后部署 |
| 本地项目目录 | 部署指定目录 |
| 当前项目 | 未提供 URL 或路径时，部署当前工作目录 |

源码物化规则见 [Phase 0](/pipeline/phases/phase-0-preflight)。

## 部署日志

每次运行创建统一的部署日志。日志贯穿所有阶段，记录阶段边界、关键决策、失败原因与重试。

Agent 不得省略日志中的阶段边界。
