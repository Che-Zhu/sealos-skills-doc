[部署模式识别](/pipeline/mode-detection) 发现运行中的应用时，用户可选择更新而非创建新实例。

UPDATE 模式运行 **Phase U1、U2 和 U3**。跳过 Phase 1、发现、模板生成与完整部署。

## 更新阶段

| 阶段 | 页面 | 任务 |
| --- | --- | --- |
| U1 | [准备更新](/pipeline/update/phase-u1-prepare) | 选择要重建的服务或要重启的工作负载 |
| U2 | [应用更新](/pipeline/update/phase-u2-apply) | 替换镜像或触发重启 |
| U3 | [验证与回滚](/pipeline/update/phase-u3-verify-rollback) | 确认 rollout 或恢复先前 digest |

## 跳过的阶段

UPDATE 不重新运行：

- Phase 1 项目评估
- Phase 2–7 发现、构建、模板生成与部署前准备
- Phase 6 完整模板部署

## 完成

rollout 成功且状态已记录时更新完成。失败时 Phase U3 回滚到最后已知良好 digest。见 [状态与完成](/pipeline/state-and-completion)。
