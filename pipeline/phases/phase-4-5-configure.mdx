## 目的

Phase 4.5 仅适用于标准构建路径。部署前 Agent 将模板配置分为四组：

| 组 | 示例 |
| --- | --- |
| 自动管理 | 应用名、内部 URL、随机秘密、托管基础设施连接 |
| 用户必填 | 管理员账号、API 密钥、SMTP、OAuth 凭证 |
| 可选 | 有合理默认的功能开关与运行时参数 |
| 固定 | 生产模式、内部端口、路径 |

## 输入

| 输入 | 来源 |
| --- | --- |
| 生成模板 | `.sealos/template/index.yaml` |
| 用户覆盖 | 存在时的 `.sealos/config.json` |

## 输出

| 输出 | 说明 |
| --- | --- |
| 最终输入集 | 绑定到模板供 Phase 5 使用 |
| 用户确认 | 明确的部署批准 |

## 流程

1. 向用户说明必填字段。
2. 收集必填值。
3. 提供可选修改。
4. 日志与最终摘要中掩码敏感值。
5. 重新校验最终模板。
6. 展示区域、镜像、依赖与配置摘要。
7. 等待明确部署确认。

## 停止条件

| 结果 | 条件 |
| --- | --- |
| **STOP** | 用户拒绝部署 |
| **STOP** | 最终模板校验失败 |
| **CONTINUE → Phase 5** | 用户确认且校验通过 |

## 验收标准

- 所有必填输入已收集
- 敏感值在日志中已掩码
- 用户确认已记录
