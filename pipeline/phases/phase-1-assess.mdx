## 目的

判断项目能否以云服务形式部署。选择快速路径或标准路径。写入 `official_template`；精确匹配时**原样拉取**官方模板至 `.sealos/template/index.yaml`。

UPDATE 模式跳过本 Phase。

不得评分。不得选择镜像。不得执行 [Phase 4](/pipeline/phases/phase-4-template) 式模板生成（转换、digest 固定、部署门禁）。不得创建云端资源。除下文官方模板原样拉取外，不得拉取或改写其他 YAML。

## 黑名单

两项均 **100% 确认** 时 **STOP**，否则 **CONTINUE**。不得因不确定或证据不足而 STOP。

| # | 条件 |
| --- | --- |
| 1 | 项目本身无法以云服务形式运行 |
| 2 | 仓库内无任何部分可以云服务部署 |

仓库是来源边界。不写产物。不对用户提示。

## 输入

| 输入 | 来源 | 必须 |
| --- | --- | --- |
| `analysis.json` | [Phase 0](/pipeline/phases/phase-0-preflight) | 是 |
| 官方模板目录 | [`kb-0.9/template`](https://github.com/labring-actions/templates/tree/kb-0.9/template) | 是 |

Phase 0 须已写入 `runtime_profile`、`work_dir`、`repo_name`。`github_url` 可为 `null`。

## 输出

| 输出 | 路径 |
| --- | --- |
| `official_template` | `.sealos/analysis.json` |
| 官方模板（精确匹配时） | `.sealos/template/index.yaml` |

```json
{
  "official_template": "https://raw.githubusercontent.com/labring-actions/templates/{commit}/template/{name}/index.yaml"
}
```

唯一精确匹配 → URL 字符串。否则 → `null`。与是否走快速路径无关。

清单与 `deployment_plan` 指针由 [Phase 2](/pipeline/phases/phase-2-discover) 写入 `analysis.json`。

## 前置条件

- [Phase 0](/pipeline/phases/phase-0-preflight) 已通过
- [部署模式识别](/pipeline/mode-detection) 为 **DEPLOY**

## 阶段约束

进入本 Phase 时须知晓，并在**执行过程中**遵守。

| ID | 约束 | 说明 |
| --- | --- | --- |
| P1-01 | 不得评分、不得选择镜像 | 评估路径，非构建 |
| P1-02 | 不得执行 Phase 4 式模板生成 | 禁止转换、digest 固定、部署门禁 |
| P1-03 | 不得创建云端资源 | 除官方模板原样拉取外，不得拉取或改写其他 YAML |
| P1-04 | 官方模板仅精确匹配 | 禁止按名称、语言或框架模糊匹配 |
| P1-05 | 黑名单须 100% 确认才 STOP | 证据不足须 CONTINUE，不得误停 |
| P1-06 | `official_template` 非 `null` 时须原样拉取 | 不得改写、合并或按当前仓库重生成 |

## 阶段验收

Phase 1 **产出落盘后**运行：

```bash
node skills/sealos-deploy/scripts/validate-phase-1.mjs --dir "$WORK_DIR"
```

脚本核对：

| ID | 核对项 |
| --- | --- |
| P1-V01 | `official_template` 为 `null` 或 labring-actions raw URL |
| P1-V02 | Phase 0 四字段保留且未被改写 |
| P1-V03 | `official_template` 非 `null` 时，`.sealos/template/index.yaml` 存在 |

未通过 → 不得 **CONTINUE → Phase 2** 或 **CONTINUE → Phase 5**。

## 流程

### 1. 黑名单判断

见上节。通过后继续。

### 2. 读取 `analysis.json`

保留 `runtime_profile`、`work_dir`、`repo_name`、`github_url`。不得修改。

### 3. 官方模板精确匹配

对照 [labring-actions/templates `kb-0.9/template`](https://github.com/labring-actions/templates/tree/kb-0.9/template) 做精确匹配。

精确匹配 = 模板声明与当前来源项目一致。不得按名称、语言或框架模糊匹配。不得做相似度匹配。

| 匹配结果 | `official_template` |
| --- | --- |
| 无匹配、多匹配 | `null` |
| 目录不可达 | `null`（不 STOP） |
| 唯一精确匹配 | 该模板 `index.yaml` 的 raw URL |

唯一精确匹配时，无论后续走快速路径或标准路径，均写入上述 URL。

**快速路径**（跳过 Phase 2–4）须同时满足：

| 条件 | 要求 |
| --- | --- |
| `official_template` | 非 `null` |
| `runtime_profile` | `sandbox`，或 `local` 且无未提交更改（排除 `.sealos/`） |

`sandbox` 不核对未提交更改。

`local` 有未提交更改 → `official_template` 仍为非 `null`，走标准路径。

### 4. 写入 `analysis.json`

写入 `official_template`。保留 Phase 0 四字段。本阶段不要求通过完整 [schema](/specs/artifact-schemas)。

### 5. 拉取官方模板

仅当 `official_template` 非 `null` 时执行：

1. 从 `official_template` URL 拉取 `index.yaml`。
2. **原样**写入 `.sealos/template/index.yaml`。不得改写、合并或按当前仓库重生成。
3. 拉取失败（URL 不可达、内容为空）→ **STOP**。

标准路径后续若进入 Phase 4，可由 Phase 4 **覆盖**本文件。快速路径在 Phase 5 直接使用本文件。

## 停止条件

| 结果 | 条件 |
| --- | --- |
| **STOP** | 黑名单两项均 100% 确认 |
| **STOP** | `official_template` 非 `null` 但官方模板拉取失败 |
| **CONTINUE → Phase 5** | `official_template` 非 `null`，且满足快速路径条件 |
| **CONTINUE → Phase 2** | 其余情况 |

## 验收标准

- `official_template` 与匹配结果一致
- Phase 0 四字段未改
- `official_template` 非 `null` 时，`.sealos/template/index.yaml` 存在且为拉取的官方 YAML 原样副本
