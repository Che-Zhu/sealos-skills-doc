## 临时工作区清理

Sealos Deploy 清理为获取远程仓库创建的临时目录。不删除用户本地项目。

GitHub URL 临时 checkout 仅在 Phase 5.5、状态验证与桥接持久化全部成功后方可删除。

## 删除不是部署阶段

删除 Kubernetes 资源、数据库、存储或测试应用不属于正常部署。

**任何删除须先获得用户明确确认。**

## 测试部署清理

用户请求清理测试部署时，Agent 必须：

1. 检查完整应用足迹：Instance、App、工作负载、网络、存储、数据库
2. 按依赖顺序删除
3. 避免遗留 Instance 层资源或删除无关应用

kubectl 删除确认与 Instance CR 要求见 [安全规则](/specs/safety-rules)。
