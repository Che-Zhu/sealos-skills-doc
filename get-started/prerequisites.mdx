使用 Sealos Skills 部署前，确认以下账号与工具。

## Sealos Cloud 账号

部署需要 Sealos Cloud 账号。`local` 环境下 Phase 0 完成区域选择、登录与工作空间选择。

## 工具

Phase 0 按运行环境自动检查并安装必装工具，无需用户逐项确认。完整规则见 [Phase 0 — 部署前环境检查](/pipeline/phases/phase-0-preflight)。

**`local` 与 `sandbox` 共用：** Git、Git LFS、Node.js 18+、Python 3.8+ 与 PyYAML、gitingest、kompose、Helm 3+、kubectl、curl、jq

**仅 `local`（Phase 3 构建路径）：** `gh`（已登录且具备 `write:packages`）、Docker CLI、运行中的 Docker daemon、Docker Buildx、railpack（`sandbox` 已预装 railpack，Phase 3 使用 **k8s-kaniko-job** skill，无需 Buildx）

## GitHub CLI 与 GHCR 访问

`local` 与 `sandbox` 均由主 Agent 在 Phase 3 将新构建镜像推送到 GHCR。`local` 须已登录 `gh` 且具备 `write:packages`；`sandbox` 使用环境注入的 `GITHUB_TOKEN` 等凭证。复用已有 digest 的路径不需要 GHCR 推送权限。

## 验证命令

```bash
docker info
gh auth status
kubectl --kubeconfig ~/.sealos/kubeconfig get ns
```

安装步骤见 [安装](/get-started/install)。
