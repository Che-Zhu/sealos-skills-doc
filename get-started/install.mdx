---
title: "安装"
description: "在 Codex、Claude Code、skills.sh 或其他支持的 AI 工具中安装 Sealos Skills。"
keywords: ["install", "codex", "claude code", "skills.sh", "plugin"]
---

在支持的 AI 宿主中安装 Sealos Skills 插件或独立 Skill。

<Tabs>
  <Tab title="Codex">
    在 Codex 市场中添加 Sealos 插件，安装后使用 `$sealos` 调用部署与其他 Skills。
  </Tab>
  <Tab title="Claude Code">
    在 Claude Code 市场中添加插件，安装后使用 `/sealos` 或 `/sealos-deploy`。
  </Tab>
  <Tab title="skills.sh">
    使用 `npx skills add` 安装独立 Skill，直接调用 `/sealos-deploy`、`/sealos-database` 或 `/sealos-s3`。
  </Tab>
  <Tab title="其他宿主">
    Gemini、Qwen、OpenClaw、CodeBuddy 等宿主支持情况见 `sealos-skills` 仓库 `distribution/platforms.json`。
  </Tab>
</Tabs>

<Info>
插件用户使用 `$sealos`（Codex）或 `/sealos`（Claude Code）。直接 `skills.sh` 用户使用 `/sealos-deploy`、`/sealos-database` 或 `/sealos-s3`。
</Info>

安装后确认 [前置条件](/get-started/prerequisites)，然后按 [首次部署](/get-started/first-deploy) 完成端到端部署。
