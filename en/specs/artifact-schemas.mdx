## `build-result.json`

Written by the main agent at the end of [Phase 3](/en/pipeline/phases/phase-3-build-push). One file holds every digest from this phase. `analysis.json` points to this file via `build_result`.

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `generated_at` | string (date-time) | No | Write timestamp |
| `digests` | object | Yes | Service/workload key → `repository@sha256:...` |
| `pull_access` | object | No | Service/workload key → pull access mode for Phase 4 |

### `pull_access` values

| Value | Meaning |
| --- | --- |
| `public` | Anonymous pull from GHCR succeeded after push |
| `ghcr_secret_required` | Anonymous pull failed or package is private; Phase 4 adds `imagePullSecrets` |

Phase 3 must set one of these two values per service. When the anonymous pull probe is inconclusive, use `ghcr_secret_required`.
