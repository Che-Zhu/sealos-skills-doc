## `build-result.json`

Written by the main agent after push in [Phase 3](/en/pipeline/phases/phase-3-build-push). Records **push outcomes**, not the template digest table. `analysis.json` points to this file via `build_result`.

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `generated_at` | string (date-time) | No | Write timestamp |
| `pushed` | object | Yes | Workload key → tag ref after push |
| `pull_access` | object | No | Workload key → GHCR pull mode for Phase 4 |

**Do not** include a `digests` field here. Template digests are written by Phase 4 to `image-digests.json`.

### `pull_access` values

| Value | Meaning |
| --- | --- |
| `public` | Anonymous pull from GHCR succeeded after push |
| `ghcr_secret_required` | Anonymous pull failed or package is private; Phase 4 adds `imagePullSecrets` |

Phase 3 must set one of these two values per pushed service. When the anonymous pull probe is inconclusive, use `ghcr_secret_required`.

Example:

```json
{
  "generated_at": "2026-08-02T14:00:00Z",
  "pushed": {
    "web": "ghcr.io/user/myapp-web:20260802-web-abc123"
  },
  "pull_access": {
    "web": "public"
  }
}
```

## `image-digests.json`

Written by [Phase 4](/en/pipeline/phases/phase-4-template) before conversion. Holds immutable digests for **every** container image in the deployment source.

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `generated_at` | string (date-time) | No | Write timestamp |
| `digests` | object | Yes | Workload key → `repository@sha256:...` (`linux/amd64`) |

Built images: resolve from tag refs in `build-result.json` → `pushed`. Upstream images: resolve from `image:` tags in the deployment source.

Example:

```json
{
  "generated_at": "2026-08-02T15:00:00Z",
  "digests": {
    "web": "ghcr.io/user/myapp-web@sha256:abc123...",
    "postgres": "docker.io/library/postgres@sha256:def456..."
  }
}
```

## `prepare-result.json`

Written by [Phase 5](/en/pipeline/phases/phase-5-prepare) after dry-run and user confirmation. Phase 6 uses it to verify the same template bytes.

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `template_sha256` | string | Yes | SHA-256 of `.sealos/template/index.yaml` (hex, lowercase) |
| `dry_run` | string | Yes | Must be `passed` |
| `user_confirmed` | boolean | Yes | `true` after explicit deploy approval |

## `deploy-result.json`

Written by [Phase 6](/en/pipeline/phases/phase-6-deploy) after a successful create request.

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `template_sha256` | string | Yes | Same as Phase 5 `prepare-result.json` |
| `app_name` | string | Yes | Online App name |
