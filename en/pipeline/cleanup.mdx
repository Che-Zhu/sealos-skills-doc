## Temp workspace cleanup

Sealos Deploy cleans temporary directories created to fetch remote repositories. It does not delete the user's local project.

A GitHub URL temp checkout may be deleted only after Phase 7, state validation, and bridge persistence all succeed.

## Deletion is not a deploy phase

Deleting Kubernetes resources, databases, storage, or test apps is not part of normal deploy.

**Any delete requires explicit user confirmation first.**

## Test deployment cleanup

When the user requests cleanup of a test deploy, the agent must:

1. Inspect the full app footprint: Instance, App, workloads, network, storage, databases
2. Delete in dependency order
3. Avoid leaving Instance-layer resources or deleting unrelated apps

See [Safety rules](/en/specs/safety-rules) for kubectl delete confirmation and Instance CR requirements.
