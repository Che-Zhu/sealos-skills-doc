## Purpose

Phase U2 applies the update without re-running assess, discovery, or template generation.

## Inputs

| Input | Source |
| --- | --- |
| Update plan | Phase U1 |
| Recorded workload map | `state.json` |

## Outputs

| Output | Description |
| --- | --- |
| Updated workloads | New digests or restarted rollouts |
| Pull secret updates | When private GHCR images require it |

## Procedure

**Image update:** update each recorded workload type, name, and container. Do not guess targets from app name alone.

**GHCR namespace rule:** all private GHCR images in the app must share one normalized namespace. Check the full service set, not only selected services. Stop before cloud changes on conflict.

**Restart only:** roll each selected Deployment, StatefulSet, or DaemonSet without image change. CronJob has no active rollout; verify image and schedule only.

Reuse existing app and network entry. One app pull secret; only workloads that need auth reference it.

## Stop conditions

| Result | Condition |
| --- | --- |
| **STOP** | Namespace conflict or apply failure before verification |
| **CONTINUE → Phase U3** | All selected changes applied |

## Acceptance

- Targets matched recorded workload map
- Pull secret consistent across auth-required workloads
