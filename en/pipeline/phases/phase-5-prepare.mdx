## Purpose

Phase 5 collects template inputs and user approval. Then it dry-runs the final YAML before deploy.

Do not create cloud resources. Do not rewrite official template content in `.sealos/template/index.yaml`.

## Prerequisites

- `.sealos/template/index.yaml` exists. [Phase 1](/en/pipeline/phases/phase-1-assess) or [Phase 4](/en/pipeline/phases/phase-4-template) wrote it.
- If the file is missing, return to the earlier phase. Do not start Phase 5.

## Inputs

| Input | Source |
| --- | --- |
| Template | `.sealos/template/index.yaml` |
| User overrides | `.sealos/config.json` when present |
| Namespace | Phase 0 (`local`) |

## Outputs

| Output | Description |
| --- | --- |
| Final input set | For [Phase 6](/en/pipeline/phases/phase-6-deploy) |
| User confirmation | Explicit deploy approval |
| Dry-run pass | No resources created |

## Procedure

### 1. Collect configuration

Classify template fields into four groups:

| Group | Examples |
| --- | --- |
| Auto-managed | App name, internal URLs, random secrets, managed infra connections |
| User-required | Admin accounts, API keys, SMTP, OAuth credentials |
| Optional | Feature flags and runtime params with defaults |
| Fixed | Production mode, internal ports, paths |

1. Tell the user which fields are required.
2. Collect required values.
3. Offer optional changes.
4. Mask secrets in logs and the summary.

### 2. Validate and dry-run

1. Validate the final template with bound inputs.
2. Dry-run the template and inputs against the Sealos deploy API. Do not create resources.
3. Show region, images, dependencies, and configuration.
4. Wait for explicit deploy approval.

If dry-run passes and the user confirms, **CONTINUE → Phase 6**.

## Stop conditions

| Result | Condition |
| --- | --- |
| **STOP** | User refuses deploy |
| **STOP** | Template validation fails or dry-run fails |
| **CONTINUE → Phase 6** | User confirms and dry-run passes |

## Acceptance

- Required inputs collected
- Secrets masked in logs
- Dry-run uses the same template bytes and parameters as Phase 6
