## Purpose

Phase 1 judges whether the project can run as a cloud service. It chooses the fast path or the standard path. It writes `official_template`.

UPDATE mode skips this phase.

Do not score the project. Do not select images. Do not run [Phase 4](/en/pipeline/phases/phase-4-template) template generation. Do not create cloud resources. Do not fetch YAML. Do not write `.sealos/template/index.yaml`.

## Blocklist

**STOP** only when both rows are **100% confirmed**. Otherwise **CONTINUE**. Do not **STOP** on uncertainty or weak evidence.

| # | Condition |
| --- | --- |
| 1 | The project cannot run as a cloud service |
| 2 | No part of the repository can deploy as a cloud service |

The repository is the source boundary. This check writes no artifact. Do not prompt the user.

## Inputs

| Input | Source | Required |
| --- | --- | --- |
| `analysis.json` | [Phase 0](/en/pipeline/phases/phase-0-preflight) | Yes |
| Official template catalog | [`kb-0.9/template`](https://github.com/labring-actions/templates/tree/kb-0.9/template) | Yes |

Phase 0 must have written `runtime_profile`, `work_dir`, and `repo_name`. `github_url` may be `null`.

## Outputs

| Output | Path |
| --- | --- |
| `official_template` | `.sealos/analysis.json` |

```json
{
  "official_template": "https://raw.githubusercontent.com/labring-actions/templates/{commit}/template/{name}/index.yaml"
}
```

One exact match → URL string. Otherwise → `null`. This is independent of the fast path.

[Phase 2](/en/pipeline/phases/phase-2-discover) writes the `deployment_plan` pointer.

## Preconditions

- [Phase 0](/en/pipeline/phases/phase-0-preflight) passed
- [Mode detection](/en/pipeline/mode-detection) is **DEPLOY**

## Procedure

### 1. Blocklist check

See the blocklist above. Continue when it passes.

### 2. Read `analysis.json`

Keep `runtime_profile`, `work_dir`, `repo_name`, and `github_url`. Do not modify them.

### 3. Official template exact match

Match against [labring-actions/templates `kb-0.9/template`](https://github.com/labring-actions/templates/tree/kb-0.9/template).

An exact match means the template declares the same source project. Do not fuzzy-match by name, language, or framework. Do not similarity-match.

| Match result | `official_template` |
| --- | --- |
| No match or multiple matches | `null` |
| Catalog unreachable | `null` (do not **STOP**) |
| One exact match | Raw URL of that template `index.yaml` |

When there is one exact match, write the URL whether or not the run later takes the fast path.

**Fast path** (skip Phases 2–4.5) requires all of:

| Condition | Requirement |
| --- | --- |
| `official_template` | Non-null |
| `runtime_profile` | `sandbox`, or `local` with no uncommitted changes (exclude `.sealos/`) |

`sandbox` does not check uncommitted changes.

On `local` with uncommitted changes, `official_template` may still be non-null. The run takes the standard path.

### 4. Write `analysis.json`

Write `official_template`. Keep the four Phase 0 fields. Full [schema](/en/specs/artifact-schemas) validation is not required in this phase.

## Stop conditions

| Result | Condition |
| --- | --- |
| **STOP** | Both blocklist rows are 100% confirmed |
| **CONTINUE → Phase 4.9** | `official_template` is non-null and fast-path conditions are met |
| **CONTINUE → Phase 2** | All other cases |

## Acceptance

- `official_template` matches the match result
- Phase 0 four fields are unchanged
- `.sealos/template/index.yaml` is not written
