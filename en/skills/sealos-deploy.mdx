## Purpose

`sealos-deploy` is the entry skill and orchestrator for full project deployments to Sealos Cloud. It runs the lifecycle defined in [Deploy pipeline](/en/pipeline/overview).

## When to use

Use when the user asks to:

- Deploy a repository or local project to Sealos
- Update an existing Sealos deployment
- Invoke `/sealos-deploy`

See [Prerequisites](/en/get-started/prerequisites) and [Phase 0 — Preflight](/en/pipeline/phases/phase-0-preflight).

## Modes

| Mode | When | Phases |
| --- | --- | --- |
| DEPLOY | No running deployment for this app | 0 → mode detection → 1–7 |
| UPDATE | Existing app recognized | 0 → mode detection → U1–U3 |

## Artifacts

All pipeline outputs live under `.sealos/` in the target project. See [Artifacts](/en/pipeline/artifacts) and [Artifact schemas](/en/specs/artifact-schemas).

## Example prompts

```
/sealos-deploy https://github.com/org/repo
/sealos-deploy ./my-app
/sealos-deploy
```

## Safety rules

- All kubectl commands use the Sealos kubeconfig with `--insecure-skip-tls-verify`
- `kubectl delete` requires explicit user confirmation
- Template API cleanup must include `instances.app.sealos.io`

See [Safety rules](/en/specs/safety-rules) and [Cleanup boundaries](/en/pipeline/cleanup).
