Sealos Skills 是一组面向 AI Agent 的工作流模块，通过插件或 `skills.sh` 安装到 Codex、Claude Code 等宿主。

## 主要 Skills

| Skill | 用途 |
| --- | --- |
| [sealos-deploy](/skills/sealos-deploy) | 部署工作负载到 Sealos Cloud |
| sealos-database | 创建并连接云数据库 |
| sealos-s3 | 创建并连接对象存储 |
| sealos-canvas | 只读查看已部署资源 |
| sealos-app-builder | 构建 Sealos Desktop 应用 |

## 支撑 Skills

| Skill | 用途 |
| --- | --- |
| dockerfile-skill | 生成生产 Dockerfile（Phase 2） |
| docker-to-sealos | 将拓扑转换为 Sealos 模板（Phase 5） |

`sealos-deploy` 是部署入口，在构建与转换阶段调用支撑 Skills。完整部署生命周期见 [流水线总览](/pipeline/overview)。
