## 目的

`sealos-deploy` 是完整项目部署到 Sealos Cloud 的入口 Skill 与编排器。它运行 [流水线总览](/pipeline/overview) 中定义的生命周期。

## 何时使用

用户请求以下操作时调用：

- 将仓库或本地项目部署到 Sealos
- 更新已有 Sealos 部署
- 调用 `/sealos-deploy`

## 前置条件

见 [前置条件](/get-started/prerequisites) 与 [Phase 0 — 部署前环境检查](/pipeline/phases/phase-0-preflight)。

## 模式

| 模式 | 时机 | 阶段 |
| --- | --- | --- |
| DEPLOY | 无此应用运行部署 | 0 → 部署模式识别 → 1–5.5 |
| UPDATE | 识别到已有应用 | 0 → 部署模式识别 → U1–U3 |

## 产物

流水线输出均在目标项目 `.sealos/` 下。见 [产物](/pipeline/artifacts) 与 [产物 Schema](/specs/artifact-schemas)。

## 示例提示

```
/sealos-deploy https://github.com/org/repo
/sealos-deploy ./my-app
/sealos-deploy
```

## 安全规则

- 所有 kubectl 命令使用 Sealos kubeconfig 并带 `--insecure-skip-tls-verify`
- `kubectl delete` 须用户明确确认
- Template API 清理须包含 `instances.app.sealos.io`

见 [安全规则](/specs/safety-rules) 与 [清理边界](/pipeline/cleanup)。
