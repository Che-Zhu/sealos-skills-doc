本文档站点是以下内容的**单一规范源（SSOT）**：

- 每个 Skill 做什么、何时运行
- 流水线阶段契约（输入、输出、停止条件）
- 模板格式与转换规则
- 产物 schema 与安全规则
- 面向用户的安装与使用说明

[`sealos-skills`](https://github.com/labring/sealos-skills) 仓库是**实现**。`SKILL.md` 与 `modules/*.md` 是本文档所定义规范的 Agent 可执行版本。

## 语言与路径

| 语言 | 路径 | 角色 |
| --- | --- | --- |
| 中文 | 根路径（`/pipeline/`、`/skills/`、`/specs/` 等） | **SSOT — 先改这里** |
| 英文 | `en/` 前缀 | 翻译，随中文 SSOT 同步更新 |

新增或修改行为规范时，先编辑根路径中文页面，再更新 `en/` 对应翻译。

## 实现对照分支

撰写、迁移或核对 `sealos-deploy` 规范时，以 [`sealos-skills` 的 `codex/review-sealos-deploy` 分支](https://github.com/labring/sealos-skills/tree/codex/review-sealos-deploy) 为**对照实现**：

| 对照文件 | 路径 |
| --- | --- |
| 流水线模块 | `skills/sealos-deploy/modules/pipeline.md`、`preflight.md`、`runtime-truth.md` |
| 转换与部署门禁 | `skills/docker-to-sealos/scripts/check_consistency.py`（规则子集见本站 [模板格式](/specs/template-format)）；`quality_gate.py` 仅 skill 开发 CI |
| 产物 schema | `skills/sealos-deploy/schemas/*.json` |
| 验收用例 | `skills/sealos-deploy/evals/evals.json` |

`main` 分支、[旧 Wiki](https://github.com/labring/sealos-skills/wiki/Sealos-Deploy-Lifecycle) 与本地 `modules/*.md` 仅作历史参考。**不得**在未核对 `codex/review-sealos-deploy` 的情况下写入新规范。

## 中文写作

根路径中文页面必须遵循 [/contributing/chinese-style](/contributing/chinese-style)（基于简明技术英语 pragmatic 模式）。

## 变更顺序

<Steps>
  <Step title="在 sealos-skills-doc 更新规范">
    编辑 `/skills/`、`/pipeline/` 或 `/specs/` 下相关页面（根路径中文）。
    以人类可读形式定义行为、契约与验收标准。
  </Step>
  <Step title="在 sealos-skills 更新实现">
    修改 `SKILL.md`、`modules/`、`scripts/`、`references/` 或 `schemas/` 以匹配规范。
  </Step>
  <Step title="添加或更新测试">
    对变更范围运行最窄的验证门控。
  </Step>
  <Step title="交叉链接 PR">
    在两个 PR 描述中互相引用文档 PR 与实现 PR。
  </Step>
</Steps>

## 内容归属

| 内容类型 | SSOT（本仓库） | 实现（sealos-skills） |
| --- | --- | --- |
| Skill 目的与触发 | `/skills/<name>.mdx` | `SKILL.md` frontmatter + usage |
| 阶段逻辑 | `/pipeline/phases/` 各页面 | `modules/pipeline.md` |
| 转换规则 | `/specs/conversion-rules.mdx` | `references/conversion-mappings.md`、`rules-registry.yaml` |
| 产物契约 | `/specs/artifact-schemas.mdx` | `schemas/*.json` |
| 安装命令 | `/get-started/install.mdx` | `distribution/platforms.json` |
| 安全规则 | `/specs/safety-rules.mdx` | `SKILL.md` 安全章节 |
| Agent 执行细节 | — | `modules/*.md`（派生，非权威） |

## 漂移检测

定期审计文档声明与实现行为及 eval 是否一致。发现漂移时，以根路径中文 SSOT 为准修正实现或文档。

<Warning>
不得在 `sealos-skills` 中改变 Skill 行为而不在本仓库更新对应规范。例外：恢复已记录行为的 bug 修复只需在 PR 中注明。
</Warning>

## 从代码优先到文档优先的迁移

现有 `sealos-skills` 内容是起始清单。按以下顺序迁移：

1. **流水线阶段** — 价值最高、变动最多
2. **各 Skill 目的与触发** — 每个 Skill 一页
3. **产物 schema** — 从 JSON schema 提取字段表
4. **转换规则** — 先建索引，逐步补充细节
5. **安装与分发** — 从 `platforms.json` 同步

带 `{/* TODO */}` 的页面是待从 `codex/review-sealos-deploy` 迁移并对齐的占位页。
